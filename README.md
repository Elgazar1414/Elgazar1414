> Research manuscript submitted to the IEEE Internet of Things Journal, 2025.  
> Manuscript ID: `IoT-56590-2025`

Developed a real-time indoor positioning system combining RSSI fingerprinting, trilateration and Wi-Fi, Bluetooth and IMU sensor fusion.

| Performance Metric | Result |

| Response Time | **Below 10 ms** |
